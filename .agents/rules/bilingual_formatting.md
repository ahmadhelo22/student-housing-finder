# Arabic and English Text Separation Rule

## Invariant:
When responding in Arabic, NEVER mix English words, library names, parameter names, or code terms inline within an Arabic sentence.

## Guidelines:
1. Every English term, identifier, parameter, or keyword must be placed on its own dedicated line.
2. Code blocks, URLs, or variable names must always appear on a separate line or within an independent block.
3. Keep Arabic sentences purely in Arabic text to avoid bidirectional (BiDi) text overlapping and misalignment issues.
